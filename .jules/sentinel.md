## 2025-03-03 - Path Traversal in File Operations
**Vulnerability:** The `UploadAuthFile` and `DeleteAuthFile` endpoints in `internal/api/handlers/management/auth_files.go` used `strings.Contains(name, string(os.PathSeparator))` to validate user-provided file names.
**Learning:** This check is insufficient because `os.PathSeparator` is OS-specific (e.g., `/` on Linux, `\` on Windows). An attacker could send a payload using the opposite separator (e.g., `..\` on Linux or `../` on Windows), bypassing the validation entirely while `filepath.Join` might still interpret it as a directory traversal sequence depending on the runtime environment.
**Prevention:** Always validate against all known path separators (`/` and `\`) using `strings.ContainsAny(name, "/\\")`. Additionally, apply `filepath.Base()` to user-provided file names as a defense-in-depth measure before joining them with base directories.

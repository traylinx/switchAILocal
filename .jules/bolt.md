## 2026-03-05 - ⚡ Bolt: Eliminate streaming chunk allocations in Gemini to OpenAI translator
**Learning:** High-frequency SSE event generators like `ConvertGeminiResponseToOpenAIResponses` experience severe GC pressure when continuously allocating empty slices (e.g., `[]any{}` for Logprobs) and new struct instances for every small token chunk. We discovered that Go handles package-level pre-allocated empty slices (`var emptyLogprobs = []any{}`) and struct pointer reuse across SSE emits highly efficiently.
**Action:** Always scrutinize streaming loops for zero-element slices and repetitive struct creations. Use pre-allocated package variables for constant empty structures and reuse struct pointers (via a persistent state object like `geminiToResponsesState`) to buffer and emit repeated high-volume events.

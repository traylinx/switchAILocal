## POST /v1/embeddings

OpenAI-compatible embeddings. Also served at `POST /openai/v1/embeddings`.

**Auth:** client API key.

The gateway reads only `model`. The JSON body is forwarded unchanged to the provider, except that `model` is rewritten to the upstream model name when you used an alias.

<ParamField body="model" type="string">
  Embedding model ID or alias (for example `ollama:nomic-embed-text` or a configured alias such as `ail-embed`). When omitted, `intelligence.matrix.embedding` is used; if that is not set either, the request fails with `400`.
</ParamField>

<ParamField body="input" type="string | string[]" required>
  Text to embed. Validated by the provider, not the gateway.
</ParamField>

<ParamField body="encoding_format, dimensions, user" type="mixed">
  Forwarded as-is. Support depends on the provider.
</ParamField>

### Which providers can serve embeddings

Embeddings work through providers that implement the `embeddings` operation:

- **Ollama**: calls Ollama's OpenAI-compatible `/v1/embeddings`.
- **OpenAI-compatible providers** (`openai-compatibility` entries, `switchai-api-key`, and any other provider handled by the generic OpenAI-compatible executor): calls `<base-url>/embeddings`.

Other providers (CLI tools, the native Gemini and Claude executors) do not have an embeddings path. Point `model` at an Ollama or OpenAI-compatible model.

### Response

The provider's response is returned unchanged with `200` and `application/json`. For OpenAI-shaped providers:

```json
{
  "object": "list",
  "data": [{"object": "embedding", "index": 0, "embedding": [0.0123, -0.0456, 0.0789]}],
  "model": "nomic-embed-text",
  "usage": {"prompt_tokens": 9, "total_tokens": 9}
}
```

Streaming is not supported.

### Examples

<CodeGroup>
```bash cURL
curl http://localhost:18080/v1/embeddings \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "ollama:nomic-embed-text", "input": ["first text", "second text"]}'
```

```python Python
from openai import OpenAI

client = OpenAI(base_url="http://localhost:18080/v1", api_key="YOUR_API_KEY")
resp = client.embeddings.create(model="ollama:nomic-embed-text", input="The quick brown fox")
print(len(resp.data[0].embedding))
```
</CodeGroup>

### Errors

| Status | When |
|---|---|
| `400` | `model not specified and no 'embedding' configured in intelligence.matrix`, or `unknown provider for model <id>` |
| `401` | Missing or invalid API key |
| upstream status | OpenAI-compatible provider errors keep their status |
| `500` | Ollama errors (for example a model that is not pulled) surface as `500` with Ollama's message |

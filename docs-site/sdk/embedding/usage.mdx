## Overview

There are two different things called "embeddings" in switchAILocal:

| | `POST /v1/embeddings` | Local embedding engine |
|---|---|---|
| Who uses it | Your application | switchAILocal itself (semantic tier, semantic cache, skill matching) |
| Backend | A provider: Ollama, an `openai-compatibility` API, a virtual model | ONNX MiniLM on your machine |
| Dimensions | Whatever the provider's model returns | 384 |
| How to call | OpenAI-compatible HTTP API | Go API inside the switchAILocal module only |

For application code (RAG, search, clustering) use `/v1/embeddings`.

## `/v1/embeddings`

The endpoint follows the OpenAI embeddings API and is routed like a chat request: the `model` field picks the provider.

### Minimal setup with Ollama

```yaml config.yaml
api-keys:
  - "sk-test-123"
ollama:
  enabled: true
  base-url: "http://localhost:11434"
  auto-discover: true
```

```bash
ollama pull nomic-embed-text
```

<CodeGroup>
```bash cURL
curl http://localhost:18080/v1/embeddings \
  -H "Authorization: Bearer sk-test-123" \
  -H "Content-Type: application/json" \
  -d '{"model": "ollama:nomic-embed-text", "input": "The quick brown fox"}'
```

```python Python
from openai import OpenAI

client = OpenAI(base_url="http://localhost:18080/v1", api_key="sk-test-123")
resp = client.embeddings.create(
    model="ollama:nomic-embed-text",
    input=["The quick brown fox", "A fast auburn fox"],
)
print(len(resp.data), len(resp.data[0].embedding))
```

```javascript Node.js
import OpenAI from 'openai';

const client = new OpenAI({ baseURL: 'http://localhost:18080/v1', apiKey: 'sk-test-123' });
const resp = await client.embeddings.create({ model: 'ollama:nomic-embed-text', input: 'The quick brown fox' });
console.log(resp.data[0].embedding.length);
```
</CodeGroup>

For Ollama, switchAILocal forwards the body to Ollama's own OpenAI-compatible `/v1/embeddings` endpoint.

### Cloud embedding models

Any `openai-compatibility` provider that has an `/embeddings` endpoint works. Give the model an alias:

```yaml config.yaml
openai-compatibility:
  - name: "mistral"
    base-url: "https://api.mistral.ai/v1"
    api-key-entries:
      - api-key: "YOUR_MISTRAL_KEY"
    models:
      - name: "mistral-embed"
        alias: "embed-default"
```

```bash
curl http://localhost:18080/v1/embeddings \
  -H "Authorization: Bearer sk-test-123" \
  -H "Content-Type: application/json" \
  -d '{"model": "embed-default", "input": "hello"}'
```

### Default embedding model

If a request has no `model`, switchAILocal uses `intelligence.matrix.embedding`. Without it, the request fails with `400 model not specified and no 'embedding' configured in intelligence.matrix`.

```yaml config.yaml
intelligence:
  matrix:
    embedding: "embed-default"
```

### Virtual models for embeddings

A [virtual model](/advanced/virtual-models) can serve embeddings if its members declare the operation. Members without `embeddings` (or `embedding`) in `capabilities.operations` are skipped for this endpoint.

```yaml config.yaml
virtual-models:
  ail-embed:
    expose: true
    members:
      - id: embed-local
        provider: ollama
        model: nomic-embed-text
        weight: 1
        capabilities:
          operations: [embeddings]
          input: [text]
          output: [text]
```

<Warning>
Different embedding models produce vectors of different sizes and in different spaces. Do not mix members with different models in one pool if you store the vectors; a weighted round-robin pool will alternate between them.
</Warning>

### Limits and troubleshooting

- Batch size and input length limits are those of the upstream model.
- `400 unknown provider for model ...`: the model ID is not registered. Check `GET /v1/models` (aliases with `expose: false` are routable but hidden).
- `422 no_eligible_backend`: a virtual model has no member with the `embeddings` operation.
- Ollama returns an error for chat-only models: pull an embedding model such as `nomic-embed-text`.

## Engine API (contributors only)

<Note>
The local engine lives in `github.com/traylinx/switchAILocal/internal/intelligence/embedding`. Go does not allow importing `internal/` packages from another module, so this API is only usable for code inside the switchAILocal repository (for example when contributing a feature). It is documented here for that audience.
</Note>

### Creating an engine

`NewEngine` does not expand `~`; resolve paths with `ModelLocator`:

```go
package example

import (
	"log"

	"github.com/traylinx/switchAILocal/internal/intelligence/embedding"
)

func newEngine() *embedding.Engine {
	loc := embedding.NewModelLocator() // BaseDir: ~/.switchailocal/models
	name := embedding.DefaultModelName // "all-MiniLM-L6-v2"
	if !loc.ModelExists(name) {
		log.Fatalf("run scripts/download-embedding-model.sh first")
	}

	eng, err := embedding.NewEngine(embedding.Config{
		ModelPath: loc.GetModelPath(name), // <BaseDir>/<name>/model.onnx
		VocabPath: loc.GetVocabPath(name), // <BaseDir>/<name>/vocab.txt
	})
	if err != nil {
		log.Fatal(err)
	}
	if err := eng.Initialize(loc.GetSharedLibraryPath()); err != nil { // "" = ONNX Runtime default lookup
		log.Fatal(err)
	}
	return eng
}
```

Inside a running server, reuse the existing engine instead of loading a second copy: `intelligenceService.GetEmbeddingEngine()` returns it, or `nil` when disabled.

### Methods

| Method | Description |
|--------|-------------|
| `NewEngine(cfg Config) (*Engine, error)` | Validates `ModelPath` is set. Does not load anything |
| `Initialize(sharedLibPath string) error` | Loads ONNX Runtime and the model, builds the tokenizer |
| `Embed(text string) ([]float32, error)` | One 384-dim, L2-normalised vector |
| `BatchEmbed(texts []string) ([][]float32, error)` | Runs `Embed` sequentially for each text |
| `CosineSimilarity(a, b []float32) float64` | Range -1 to 1; returns 0 for empty or mismatched lengths |
| `IsEnabled() bool` | `true` after a successful `Initialize` |
| `GetDimension() int` | Always 384 |
| `Shutdown() error` | Releases the ONNX session |

`Config` has `ModelPath`, `VocabPath` and `SharedLibraryPath`. If `VocabPath` is empty or unreadable, a tiny built-in vocabulary is used, which produces poor embeddings; always ship `vocab.txt`.

Constants: `DefaultModelName = "all-MiniLM-L6-v2"`, `EmbeddingDimension = 384`, `MaxSequenceLength = 256`.

### Errors

| Error text | Cause |
|------------|-------|
| `model path is required` | `NewEngine` called with empty `ModelPath` |
| `model file not found: ...` | `Initialize` could not stat the model file |
| `failed to initialize ONNX runtime` | Shared library missing or wrong architecture |
| `embedding engine not initialized` | `Embed` before `Initialize`, or after `Shutdown` |
| `tokenization failed` / `inference failed` | Input could not be tokenised, or the ONNX graph has unexpected inputs/outputs |

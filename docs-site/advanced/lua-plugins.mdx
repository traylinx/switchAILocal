The Lua plugin system lets you run small scripts on every request: rewrite the model, pin a provider, edit the JSON body, or log what happened. It is the mechanism behind the [Cortex Router](/intelligent-systems/cortex-router), which handles `model: "auto"`.

Plugins run inside an embedded [gopher-lua](https://github.com/yuin/gopher-lua) VM with a reduced standard library and a `switchai` host module.

## When to use it

- Route requests by content (for example, send long prompts to a long-context model).
- Inject a system prompt or default fields into specific requests.
- Log or record feedback about completed requests.

For static field defaults/overrides per model, [Payload Injection](/advanced/payload-injection) is simpler and runs later in the pipeline. For weighted pools of backends, use [Virtual Models](/advanced/virtual-models).

## Quick start

<Steps>
  <Step title="Enable the engine">
    ```yaml config.yaml
    plugin:
      enabled: true
      plugin-dir: "./plugins"      # no default: set it explicitly
      enabled-plugins:
        - "cortex-router"
    ```
    Only plugins listed in `enabled-plugins` are loaded. An empty list loads nothing, even if `enabled: true`.
  </Step>
  <Step title="Restart switchAILocal">
    Plugins are loaded once at startup. Changing the plugin files or the `plugin:` block requires a restart.
    ```text
    level=info msg="loading plugin: Cortex Intelligent Router (cortex-router)"
    ```
  </Step>
  <Step title="Send a request the plugin handles">
    ```bash
    curl http://localhost:18080/v1/chat/completions \
      -H "Authorization: Bearer sk-test-123" \
      -H "Content-Type: application/json" \
      -d '{"model": "auto", "messages": [{"role": "user", "content": "Write a Go HTTP server"}]}'
    ```
  </Step>
</Steps>

## Plugin layout

Each plugin is a directory inside `plugin-dir`:

```text
plugins/
└── my-plugin/
    ├── schema.lua    # metadata, must return a table
    └── handler.lua   # logic, should return a table with hook methods
```

Rules enforced by the loader (`internal/plugin/lua_engine.go`):

- The directory name must be a lower-case slug: `^[a-z0-9]+(-[a-z0-9]+)*$`.
- `schema.lua` must return a table whose `name` equals the directory name.
- `handler.lua` is compiled at startup and its top-level chunk runs again on every hook call. It should return a table; if it does not, global functions named `on_request` / `on_response` are used instead.
- `require("x")` resolves `x.lua` inside the plugin directory first.

```lua schema.lua
return {
    name = "my-plugin",
    display_name = "My Plugin",
    version = "1.0.0",
    description = "Routes long prompts to a long-context model"
}
```

```lua handler.lua
local Plugin = {}

function Plugin:on_request(req)
    -- Leave explicitly prefixed requests (e.g. "ollama:llama3.2") alone
    if req.provider and req.provider ~= "" then
        return nil
    end
    if req.body and #req.body > 200000 then
        switchai.log("[my-plugin] long prompt, rerouting")
        req.model = "deepseek-v4-pro"
        return req
    end
    return nil   -- nil = no change
end

return Plugin
```

## Hooks

### `on_request(self, req)`

Runs before routing for chat, completions, Responses, Claude Messages, embeddings, image, audio and music requests.

Fields of `req`:

| Field | Type | Present |
|---|---|---|
| `model` | string | always. For `provider:model` requests this is the part after the colon. |
| `provider` | string | only when the client used a known provider prefix such as `ollama:` or `geminicli:` |
| `body` | string | always; the raw JSON request body |
| `metadata` | table | always (may be empty); internal routing metadata such as thinking-suffix data |
| `api_key` | string | when a credential exists for the explicit provider, or for the provider inferred from a `name:model` ID or a `minimax...` model |

Return `nil` to leave the request unchanged, or return the (modified) table. These fields are read back:

| Field | Effect |
|---|---|
| `model` | replaces the model ID used for routing |
| `provider` | pins the request to this provider ID. For unprefixed requests this skips virtual-model and auto-routing resolution. |
| `body` | replaces the request body (must stay a JSON string) |
| `metadata` | replaces routing metadata |

<Warning>
Only a single `provider` string is honoured. A `providers` list returned from Lua is currently ignored (Lua arrays are converted to generic lists, which the router does not accept).
</Warning>

### `on_response(self, res)`

Runs after a **successful non-streaming** request. It is observation-only: the return value is ignored, so you cannot rewrite the response here. Streaming responses do not call it.

Fields of `res`: `body` (response JSON string), `model`, `provider`, `metadata`, `original_query` (the request body).

### Execution order

All loaded plugins run for every hook. The order between plugins is not defined; each plugin receives the table returned by the previous one. A hook that raises an error is skipped (logged at debug level) and the next plugin continues with the unmodified input.

Requests issued by `switchai.classify` itself skip the unprefixed `on_request` hook to avoid recursion.

## The `switchai` host module

### Core functions

| Function | Returns | Notes |
|---|---|---|
| `switchai.log(msg)` | — | logs at info level with a `[LUA]` prefix |
| `switchai.classify(prompt)` | `string` or `nil, err` | sends the prompt to `intelligence.router-model` with the Cortex classification system prompt; returns the raw model text (decode it yourself) |
| `switchai.json_decode(str)` | `table, nil` or `nil, err` | |
| `switchai.json_encode(tbl)` | `string, nil` or `nil, err` | |
| `switchai.json_inject(body, text)` | `string` | prepends `{"role":"system","content":text}` to `messages`; returns the input unchanged if it has no `messages` |
| `switchai.get_cache(key)` / `switchai.set_cache(key, value)` | `string` or `nil` | process-wide string cache shared by all plugins; cleared completely when it exceeds 1000 entries |
| `switchai.config` | table | `router_model`, `router_fallback`, `skills_path`, `matrix` (copy of `intelligence.matrix`) |
| `switchai.scan_skills(path)` | table or `nil, err` | parses `SKILL.md` files under `path` |
| `switchai.exec(cmd, ...)` | `output` or `output, err` | allowlisted commands only, see below |
| `switchai.mcp_call(cmd, args, env, tool, tool_args)` | `output, err` | runs one MCP tool over stdio, see below |

Example: classify and branch.

```lua
local raw, err = switchai.classify(req.body)
if raw then
    local decision = switchai.json_decode(raw)
    if decision and decision.intent == "coding" then
        req.model = switchai.config.matrix.coding or req.model
        return req
    end
end
return nil
```

`openai_vision_to_text` and `minimax_native_vlm_extract` are helpers used by the bundled MiniMax plugin to replace image parts with a text description.

## Sandbox and limits

- Loaded libraries: base, `table`, `string`, `math`, `package`. There is no `io` library and no `os.execute`; `os` only provides `os.date` and `os.time`. `dofile` and `loadfile` are removed.
- `switchai.exec` allows only `ls`, `cat`, `echo`, `date`, `git`, `whoami`, `pwd`, `grep`. For `git`, only `status`, `diff`, `log`, `show`, `branch`, `ls-files`, `grep` are allowed. Each call has a 5 second timeout and output is truncated to 8 KB.
- `switchai.mcp_call` allows only the launchers `uvx`, `npx`, `node`, `python3`, with a 30 second timeout. The child inherits the server environment plus the `env` table you pass.
- `on_request` runs without its own deadline. Keep hooks fast; a slow hook delays every request.

<Warning>
Plugins see full request bodies and, through `api_key`, provider credentials. Only enable plugins you have read.
</Warning>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Plugin is not loaded">
    - `plugin.enabled` must be `true`, `plugin-dir` must point to an existing directory, and the plugin ID must be in `enabled-plugins`.
    - Look for `failed to load plugin <id>` or `skipping plugin with invalid directory name` in the startup log. The most common cause is `schema.name` not matching the directory name.
  </Accordion>
  <Accordion title="Hook seems to do nothing">
    - Return the modified `req` table; returning `nil` means no change.
    - Errors inside a hook are only logged at debug level. Set `debug: true` to see `hook on_request in <plugin> returned error`.
    - `on_response` cannot change the response and is not called for streaming requests.
  </Accordion>
  <Accordion title="A counter or table at the top of handler.lua resets on every request">
    `handler.lua` is compiled once but its top-level chunk is executed again for every hook call, in a pooled VM. `local` variables declared at file level do not survive between requests. Keep state in `switchai.set_cache` / `switchai.get_cache`.
  </Accordion>
  <Accordion title="command not allowed / MCP command is not in the security whitelist">
    The command is outside the allowlists listed above. There is no configuration to extend them.
  </Accordion>
</AccordionGroup>
